# Hospital Performance & Patient Outcomes Analytics

## Overview

This project presents a healthcare data analytics workflow for examining hospital utilization, patient outcomes, length of stay, readmissions, mortality, and patient flow.

The project combines Python-based data preparation and feature engineering with Microsoft Power BI for interactive healthcare dashboard development.

---

## Project Objectives

The project aims to:

- Analyze hospital admission patterns
- Examine length of stay
- Assess in-hospital mortality
- Analyze 30-day readmissions
- Identify long-stay admission patterns
- Explore patient transfer activity
- Examine multiple-admission patterns
- Develop an interactive healthcare analytics dashboard

## Dashboard

The Power BI dashboard contains six pages:

### 1. Executive Overview

High-level hospital performance indicators.

### 2. Hospital Utilization

Analysis of admissions, length of stay, and utilization patterns.

### 3. Patient Outcomes

Analysis of mortality, readmission, and patient outcome patterns.

### 4. Patient Flow

Analysis of transfers, care-unit movement, and multiple admissions.

### 5. Performance Analysis

Comparison of major hospital performance indicators.

### 6. About & Methodology

Project methodology, indicators, and analytical limitations.
